# 블루레오파드 — 비공개 스페셜 소재

- ID `BLUE LEOPARD`, 표시 이름 `블루레오파드`. 관리자와 기존 비밀 공유 링크에서만 제공하며 공개 일반 컬러에는 추가하지 않는다.
- 첨부 자켓의 네이비 바탕, 코발트 블루의 길쭉하고 불규칙한 로제트, 미세 새틴 결을 참고한 소재 타일이다. 자켓 사진의 재단선·국기·로고·금색 장식은 포함하지 않는다. 평면 원단을 실측 스캔한 자료는 아니다.
- 네이티브 1424×1392 신발 사진에서 반복 주기 420px. 부위마다 기존 독립 재단 오프셋을 유지해 B/C/D 경계에서 무늬가 억지로 이어지지 않는다. 방향은 원본 타일 기준이며 거울 반사를 사용하지 않는다.
- 반복 경계에만 6% 겹침을 적용하고 나머지 내부 픽셀은 보존한다. 사전 축소를 0.94로 보정해 겹침 뒤에도 의도한 무늬 밀도를 유지한다.
- 기존 RED 레이어의 투명 경계와 스티치를 사용하고 GOLD 기반 곡면 조명에 새틴 광택을 더한다. 광원 blur 24, diffuse floor 0.36, peak 1.16, sheen 0.022. 기존 B/C 두 줄 스티치 복원을 최종 단계로 유지한다.
- 가죽은 장목 9부위·중목 8부위에 적용하며 중목 G는 만들지 않는다. 2026-11-13 후속 요청으로 두 모델의 A 메쉬에도 별도 선택을 추가했다. 끈·비즈·밑창은 별도 설정을 유지한다.

검증: `node scripts/blue-leopard-render-smoke.mjs <packaged-blue-leopard.jpg> <output-dir> origin/main`.
선택 QA 의존성 `@napi-rs/canvas`가 필요하다. 실제 17부위 렌더의 원본 알파 일치와 영역 밖 번짐 없음, 반복 경계 완화·내부 픽셀 보존, 기존 소재 16개 렌더의 바이트 동일성을 검사하고 전체 신발 및 B/C 스티치 확대 이미지를 저장한다.

## A 메쉬 블루레오파드

- 기존 보호 소재를 재사용하며 새 이미지·서버 키·공개 팔레트를 만들지 않는다. 관리자 및 기존 유효 공유 링크에서만 A의 `블루레오파드` 버튼을 제공한다.
- `SpecialDraft.meshPattern`은 가죽 `patterns`, 일반 주문 색상, 끈 및 비즈와 별도다. 단색 A를 선택하거나 초기화하면 해제된다. 모델별 임시 선택·추천 후 이전 디자인 복원·인증 해제 동작을 유지한다.
- `blue-leopard-mesh.ts`는 1424×1392 원본 A 알파와 기존 끈 분할 마스크를 사용한다. 동일한 420px 패턴과 6% 반복 경계를 쓰며 A만의 재단 오프셋을 적용한다. 원본 A의 넓은 곡면 조명을 유지하되 3px 평활화로 기존 굵은 메쉬 격자를 완화한다.
- 모든 순수 끈 픽셀은 기존 8색 렌더와 동일하며 가장자리에서는 기존 안티앨리어싱 분할 비율로 한 번만 합성한다. 비즈는 기존 마스크에 마지막으로 합성한다.
- 소재 로딩/실패 중 합성 JPEG 저장을 차단하고 A 단색 선택으로 돌아갈 수 있게 한다. 로그아웃 직후 남은 이전 버튼 콜백도 차단한다.
- `blue-leopard-mesh-state-smoke.mjs`: 상태·권한·복원·모델·저장 8그룹 통과. `blue-leopard-mesh-render-smoke.mjs <texture.jpg> <output-dir>`: 두 모델 원본 알파, 끈8색 픽셀 보존, 끈/메쉬 독립, 비즈 영역 제한 통과. Canvas 검사는 별도 QA 의존성을 사용한다.
