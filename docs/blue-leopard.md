# 블루레오파드 — 비공개 스페셜 소재

- ID `BLUE LEOPARD`, 표시 이름 `블루레오파드`. 관리자와 기존 비밀 공유 링크에서만 제공하며 공개 일반 컬러에는 추가하지 않는다.
- 첨부 자켓의 네이비 바탕, 코발트 블루의 길쭉하고 불규칙한 로제트, 미세 새틴 결을 참고한 소재 타일이다. 자켓 사진의 재단선·국기·로고·금색 장식은 포함하지 않는다. 평면 원단을 실측 스캔한 자료는 아니다.
- 네이티브 1424×1392 신발 사진에서 반복 주기 420px. 부위마다 기존 독립 재단 오프셋을 유지해 B/C/D 경계에서 무늬가 억지로 이어지지 않는다. 방향은 원본 타일 기준이며 거울 반사를 사용하지 않는다.
- 반복 경계에만 6% 겹침을 적용하고 나머지 내부 픽셀은 보존한다. 사전 축소를 0.94로 보정해 겹침 뒤에도 의도한 무늬 밀도를 유지한다.
- 기존 RED 레이어의 투명 경계와 스티치를 사용하고 GOLD 기반 곡면 조명에 새틴 광택을 더한다. 광원 blur 24, diffuse floor 0.36, peak 1.16, sheen 0.022. 기존 B/C 두 줄 스티치 복원을 최종 단계로 유지한다.
- 장목 9부위·중목 8부위에 적용하며 중목 G는 만들지 않는다. 메쉬·끈·비즈·밑창에는 적용하지 않는다.

검증: `node scripts/blue-leopard-render-smoke.mjs <packaged-blue-leopard.jpg> <output-dir> origin/main`.
선택 QA 의존성 `@napi-rs/canvas`가 필요하다. 실제 17부위 렌더의 원본 알파 일치와 영역 밖 번짐 없음, 반복 경계 완화·내부 픽셀 보존, 기존 소재 16개 렌더의 바이트 동일성을 검사하고 전체 신발 및 B/C 스티치 확대 이미지를 저장한다.
