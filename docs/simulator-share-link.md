# 스페셜 시뮬레이터 고정 공유 링크

관리자가 `/customize`에 로그인한 상태로 들어가면 모델 선택 아래에 **공유 링크 복사**, **공유 화면 열기**가 표시된다. 공유 링크를 받은 사람은 로그인 없이 장목·중목의 현재 스페셜 소재를 선택하고 시안을 저장할 수 있다. 링크에는 만료 시간이나 사용 횟수 제한을 두지 않았다.

일반 메뉴와 사이트맵에 공유 링크를 넣지 않는다. `/special` 응답에는 검색 제외와 캐시 금지 헤더를 설정한다. 링크를 전달받은 사람이 다시 전달하면 다음 사람도 사용할 수 있다.

## 접근 범위

- 기존 관리자 세션: 기존 관리자 기능과 공유 링크 조회 가능.
- 공유 링크: 스페셜의 `ping`·`assets`만 가능. 관리자 세션을 생성하거나 저장하지 않는다.
- 일반 방문·잘못된 링크: 스페셜 자료 접근 불가.
- 공개 시뮬레이터의 장목·중목, 색상, 이미지, 주문 처리는 변경하지 않는다.

## 서버 설정

Railway의 기존 서비스 환경변수 `SIMULATOR_SPECIAL_SHARE_TOKEN`에 32바이트 암호학적 난수의 소문자 hex 문자열(64자)을 저장한다. 실제 값은 소스·문서·공개 번들에 기록하지 않는다. 주소 형식은 `https://jidokaan.com/special#key=<token>`이다. Fragment 값은 페이지 탐색 HTTP 요청과 Referer에 포함되지 않으며, 자료 요청 시 같은 사이트 서버로 POST한다.

기존 `/api/simulator-special`의 `share-link` 액션은 실제 관리자 세션을 검사한 뒤 고정 URL을 반환한다. 공유 토큰은 해당 액션이나 다른 관리자 API의 인증 수단으로 인정하지 않는다. 값이 누락되면 공유는 차단되고 기존 관리자 접근은 유지된다.

링크를 교체해야 할 때만 서버 환경변수를 새로운 난수로 바꾸고 재배포한다. 교체 후 기존 링크는 무효이며 관리자 복사 버튼이 새 링크를 제공한다. 평소 배포에서는 이 값을 변경하지 않는다.

## 확인

`node scripts/simulator-share-smoke.mjs`로 공유·관리자 권한 분리와 두 모델의 자료 반환을 확인한다. 기존 `public-simulator-catalog-smoke.mjs`, `simulator-special-smoke.mjs`, 타입 검사 및 Node 서버 빌드도 함께 확인한다.
