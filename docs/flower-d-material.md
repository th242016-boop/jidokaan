# FLOWER D

2026-11-08: 파랑·민트 잎, 노란 꽃, 레오퍼드 무늬가 섞인 실물 가죽 사진을 다음 플라워 순번인 **FLOWER D**로 추가했다.

- 관리자와 기존 고정 공유 링크의 스페셜에서 장목 B–J, 중목 B–F/H–J에 적용한다. 일반 공개 시뮬레이터·공개 소재 허용 목록은 변경하지 않는다.
- 원본 `KakaoTalk_20261108_165955258(1).jpg`(1153×2048)를 수정 없이 AES-256-GCM으로 보관한다. SHA-256: `79e9191b897304049da888d479273caa744cf810966cb1b86af5ab7263dd7ad0`.
- 손과 배경을 제외한 `(170,130,960,960)` 영역을 옵션 이미지와 실제 부위의 공통 원본으로 사용한다. 파일: `src/lib/special-assets/material-flower-d-photo.enc`. 독립 서버 환경변수: `SIMULATOR_FLOWER_D_KEY`(32바이트 키, base64). 기존 소재 키와 공유 토큰은 교체하지 않는다.
- 예시 신발을 기준으로 1424×1392 화면에서 타일 주기360px로 조절했다. 실제 재단 치수의 보증값은 아니다. 부위별 시작점과 작은 회전 차이를 두며, 꽃이 거울처럼 복제되지 않도록 정상 반복과6% 경계 겹침을 사용한다.
- 기존 RED 이미지의 투명 경계와 GOLD 이미지의 중립화한 넓은 조명을 사용한다. 약한 새틴 광택과 실제 스티치 복원을 적용하며 B/C 이중선을 유지한다.
- 키 누락·오류 또는 자료 손상 시 FLOWER D만 제외하고 나머지 소재는 유지한다.

검증: `node scripts/flower-d-render-smoke.mjs <original.jpg> <output-dir> 7801b6b`(선택 QA 의존성 `@napi-rs/canvas` 필요). 전체17부위의 원본 알파 일치·영역 밖 번짐 없음, 기존 소재16개 렌더 결과의 동일성을 확인한다. 공개 카탈로그·스페셜·공유 링크 smoke, 타입 검사, Node 서버 빌드도 실행한다.
