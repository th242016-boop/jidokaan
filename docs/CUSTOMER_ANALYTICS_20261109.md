# 고객관리 · 유입분석 변경 (2026-11-09)

기준 소스: main fd2da9e4703d93a0f36c345c3c75262bbac6fa53. 기존 사이트/시뮬레이터/주문/회원의 값을 삭제하거나 재생성하지 않는 추가 변경.

## 화면과 API
- 관리자 데이터분석 > 고객관리 (`/admin?p=customers`). 이름/실제 이메일/휴대폰 검색, 가입방법(구글/네이버/카카오/이메일), 가입경로(PC/모바일/태블릿), 유입경로, 가입일 필터. 기본20, 50/100행 선택, 검색결과/전체 수와 페이지 이동.
- `/api/members`는 관리자 Bearer 인증, 기존 query token도 호환. 서버 SQL count/limit/offset으로 페이지를 조회하며 모든 회원을 내려보내지 않는다.
- 내부 소셜 식별용 `@login.jidokaan.com` 이메일은 DB 원본을 유지하되 응답에서는 빈 이메일/emailUnavailable로 표시. 실제 이메일/휴대전화가 없으면 미제공이다. 보이는 닉네임을 법적 실명으로 검증한 것은 아니다.
- 기존 주문 고객 집계는 접힌 별도 영역에서 필요 시 조회. 해당 합계는 기존처럼 미결제/취소 포함 주문기록이며 결제완료 매출이 아니다.
- 유입·키워드 화면은 최근500행이 아닌 선택 기간 전체를 집계. 한국시간 날짜, 7/30/90일, 상품명/현재 카탈로그 대표사진/페이지 이름/바로가기 제공. 결제전환율처럼 오해할 통계는 제거; 조회/장바구니/주문 이벤트를 구분.

## 수집 방식과 한계
- 신규 회원 생성 BetterAuth `databaseHooks.user.create.after`에서만 가입 당시 기기와 브라우저 유입정보 저장. 기존회원은 과거기록 없음; 재로그인으로 소급 채우지 않음.
- migration0012는 member_signup_attribution 테이블 및 조회 인덱스만 추가. 가입정보는 중복저장/덮어쓰기 방지, 생성5분이내 보호조건.
- 가입기기는 User-Agent 기반 범주 추정, 유입은 브라우저가 전달한 값이며 검증된 고객 신원이 아니다.
- 브라우저 탭 세션의 첫 유입을 sessionStorage와 최대24시간 자사 쿠키에 보관. www/루트 도메인 OAuth 이동에도 유지. 개인정보 처리 안내에 이 수집목적 추가.
- 수집 허용: utm_source/medium/campaign/term, n_keyword/n_query, 알려진 검색엔진 referrer의 실제 q/query. 일반 랜딩URL의 q/이메일/인증코드/문의비밀키를 유입검색어로 저장하지 않는다. referrer origin과 pathname만 보관. IP/기기지문 추가수집 없음.
- 검색엔진이 검색어를 전달하지 않으면 미제공으로 표시. Google Search Console 등 집계 검색어 연동은 아직 없음; 특정회원의 비공개 검색어를 알아낼 수 있다고 주장하지 말 것.
- 과거 자기사이트/소셜로그인 도메인 유입기록은 원본을 유지하고 유입순위에서 제외. 당시 실제 외부출처를 복원하지는 못한다.
- 조회수는 고유 방문자수가 아니다. 브라우저 주문 이벤트는 결제완료 매출과 다르다. 광고 차단/저장소 차단 시 일부 정보가 없을 수 있다.

## 국내 직접결제 검토 (연동 미실행)
현재 국내 checkout은 네이버스토어 이동이며, 토스 설정 입력칸만으로 PG가 실제 연결된 것은 아니다.
28만8천원 상품 예시, 영세등급 가정, VAT포함 결제수수료:
- 네이버 기본: Npay1.947% + 판매3% =4.947%, 약14,247원/건.
- 네이버 판매자 마케팅링크:1.947%+1%=2.947%, 약8,487원/건.
- 포트원 경유 토스 공시 영세요율1.65%+VAT=1.815%, 약5,227원/건. 실제계약 견적 보장 아님.
월50건이면 자체결제의 거래수수료 차이 약163,008~451,008원. PG가입비/관리비/보증보험/개발운영비/광고비/할인/배송비 등 제외. 세후순이익 분석 아님.
토스 직계약 일반공시는3.4%+VAT=3.74%이므로 영세 네이버마케팅보다 비쌀 수도 있다. 네이버 실제등급과 PG계약조건 확인 후 결정.
포트원 공시 토스 가입비22만원(VAT포함), 관리비/보험은 견적확인. 토스 직계약 참고공시는 가입22만원+연11만원(계약별차이); 이를 제휴조건 확정값으로 합산하지 말 것. 포트원 플랫폼 월순거래5천만원미만 무료구간.
